## 免费联网观察

中文姓名查询本轮两版均由 Bing RSS 返回 3 个相同 URL，Node 约 2.6 秒、Python 约 4.1 秒。DuckDuckGo 的 DNS 地址触发了安全拒绝，随后切换到 Bing，没有放松内网限制。不能把这个耗时当成普遍性能。

来源复核：第一条[学校原始页面](https://ai.ruc.edu.cn/szdw/zrjs/myb/index.htm)含精确姓名与个人介绍，可用于该人物身份核实；第二条为 [GitHub Pages 聚合页面](https://academiconnection.github.io/ruc_gsai_faculty_network/ruc_gsai_mayanbiao_network/)，不能当独立第一手证明；第三条非学校域名页面未能通过外部读取复核，不作为可靠证据。返回 3 条不等于 3 条可信来源，也不构成已排除同名歧义。

两版均在 [Python 官方文档](https://docs.python.org/3/library/asyncio-task.html#task-groups)定位到 TaskGroup 的等待行为，并返回真实章节锚点。修复了导航标题使正文标题索引错位的问题。

论文先通过外部搜索找到 [Attention Is All You Need 原始论文](https://arxiv.org/abs/1706.03762)，未把 ID 写入工具查询规则。真实 PDF 测试中 Python 成功提取并找到结论；Node 一次下载耗尽 30 秒。不能声称长论文读取已经完全稳定。物理页定位依据提取分页标记，不是印刷页码。
